## 🛠 Open-Source Projects

<table>
<tr>
<td width="50%" valign="top">

### 🔭 [OpenSRE](https://github.com/Tracer-Cloud/opensre)

**An open-source AI SRE benchmark + agent runtime.** Turns a raw alert into a structured root-cause analysis by running an LLM ReAct loop against 60+ observability, cloud, database, and incident-management tools. Investigations run on your own infrastructure — bring your own LLM (Anthropic, OpenAI, Bedrock, Ollama, …).

**My contributions:** terminal-renderer test coverage ([#2606](https://github.com/Tracer-Cloud/opensre/pull/2606), merged), Dockerfile build regression suite ([#2620](https://github.com/Tracer-Cloud/opensre/pull/2620)), synthetic test analysis ([#2599](https://github.com/Tracer-Cloud/opensre/issues/2599)).

<sub>Stack: Python · FastAPI · Docker · Terraform · AWS · Postgres · Redis</sub>

</td>
<td width="50%" valign="top">

### ✨ [everything-claude-code](https://github.com/maheshsv/everything-claude-code)

**A harness-native operator system for agentic work with Claude Code.** Ships ~20 language-specific rule packs (Python, TypeScript, Go, Rust, Java, Kotlin, Swift, C++, C#, Ruby, PHP, Dart, F#, Perl, ArkTS, Angular, web…), 50+ agents, slash commands, hooks, and platform configs.

**My customizations:** tuned for Python / web / agentic SRE workflows, with hooks and rule overrides for my own day-to-day. Used daily across my open-source contributions (OpenSRE and others).

<sub>Stack: Shell · TypeScript · Python · Markdown · npm — based on [ECC](https://github.com/affaan-m/ECC) by [@affaan-m](https://github.com/affaan-m), MIT</sub>
